# yah265 comparisons

Side-by-side players for [yah265](https://github.com/terranvigil/yah265) and x265 encodes of open clips at the same file size, served with GitHub Pages. Each folder is a static export of the [veo](https://github.com/terranvigil/veo) comparison player. How each encode was made is in its player's "How this was made" panel.

- `nocturne-4k/`: Nocturne (c) Netflix, Inc., Netflix Open Content, CC BY 4.0.
- `sparks-1080p/`: Sparks (c) Netflix, Inc., Netflix Open Content, CC BY 4.0.
- `screen-wikipedia/`: Wikipedia screen recording by Thomas Daede, CC0 1.0, from the AOM CTC screen-content set. The page text is Wikipedia's, CC BY-SA 4.0.

The excerpts were cut and re-encoded for these comparisons.
